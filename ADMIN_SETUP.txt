ملاحظة أمنية:
تم عدم وضع كلمة المرور كنص صريح داخل ملفات الموقع. الـBackend يستخدم SHA-256 لها.
لا ترفع أي ملف يحتوي على كلمة المرور إلى GitHub.

تشغيل الـBackend على VPS:
1) افتح مجلد backend
2) npm install
3) npm start
4) سيعمل افتراضياً على المنفذ 3000

قاعدة البيانات والدفع والإيميلات وربط MTA لم تُفعّل بعد؛ هذه النسخة مرحلة الموقع/الـBackend الأولية.
