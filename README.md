VALORIA Store — ملفات منفصلة وجاهزة للرفع

ارفع كل الملفات والمجلدات كما هي إلى جذر مستودع GitHub:
- index.html
- style.css
- app.js
- data/ (ملف مستقل لكل قسم)
- assets/ (صور كل المنتجات)

المنتجات:
ملف data/vehicles.js يحتوي المركبات المتاحة من بيانات سابقة:
GMC Sierra 1998 ID 1025، Toyota Hilux 2016 ID 1026، Ambulance Hospital 1990 ID 1027، Chevrolet Tahoe 2020 (Police Pursuit).
أضف السعر والمخزون والصورة لكل منتج داخل الملف. الصور توضع في assets/vehicles/ وبالأسماء المكتوبة في image.
باقي ملفات الأقسام موجودة وفاضية لحد إدخال بيانات المنتجات الحقيقية. أضف عناصر بنفس بنية كائنات المركبات، مع category المطابق لاسم القسم.

النشر:
GitHub > المستودع Valoria > Add file > Upload files، ارفع محتويات المجلد (وليس مجلد ZIP نفسه) ثم Commit changes.
Settings > Pages > Deploy from a branch > main > /(root) > Save.

تنبيه: صور المركبات الفعلية غير متوفرة هنا، لذلك جهزت مساراتها ولم أضع صوراً تخمينية. كذلك لا تتوفر أسعار أو مخزون موثق. السلة تجريبية ولا يوجد دفع أو تسليم آلي/ربط MTA.
