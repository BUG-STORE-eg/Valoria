VALORIA Complete Store — جاهز للنشر على GitHub Pages

1) فك ضغط الملف.
2) ارفع index.html إلى جذر مستودع GitHub الخاص بك (Valoria)، واستبدل الملف القديم إذا لزم.
3) افتح Settings > Pages.
4) اختر Deploy from a branch ثم main و /(root)، واضغط Save.
5) افتح رابط GitHub Pages بعد اكتمال النشر.

تعديل المنتجات:
افتح index.html وابحث عن const products=[ ... ].
كل عنصر يحتوي id و name و category و price و stock و icon.
غيّر الأمثلة إلى منتجاتك وأسعارها الفعلية. الصور: يمكن إضافة مجلد assets ثم استخدام مسارات الصور بعد تعديل القالب.

مهم:
المنتجات الحالية أمثلة مؤقتة وليست منسوخة من متجر ULG، لأن بيانات كل المنتجات وأسعارها وصورها لم تتوفر بشكل قابل للاستخراج المؤكد.
هذا قالب Front-end ثابت؛ السلة تجريبية ولا يوجد دفع أو تسليم تلقائي أو ربط بقاعدة بيانات/MTA. هذه الوظائف تحتاج Backend آمن وخدمة دفع.
