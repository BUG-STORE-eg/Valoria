# VALORIA ROLEPLAY Store
## رفع المتجر
1. فك ضغط الملف.
2. ارفع محتويات المجلد إلى جذر مستودع GitHub `BUG-STORE-eg/Valoria` مع الحفاظ على مجلد `data` و`assets`.
3. اعمل Commit changes وانتظر تحديث GitHub Pages.
4. افتح https://bug-store-eg.github.io/Valoria/
## تعديل المنتجات
كل المنتجات حاليًا في `data/products.js` كمصفوفة `window.VALORIA_PRODUCTS`. عدّل الاسم والتصنيف والسعر والكمية ومسار الصورة.
## تنبيه
الصور داخل assets قصاصات من لقطات الشاشة المرسلة، وليست ملفات موديلات أصلية منفصلة. راجع دقة النصوص المقروءة من الصور قبل البيع. زر الشراء والسلة تجريبيان فقط، ولا يوجد دفع أو تسليم آلي متصل.

## تحديث التصميم الأحمر والأقسام
- تم حذف سطر المخزون (مثل «يوجد 999 من المنتجات») من بطاقات المنتجات.
- الأقسام أصبحت في شريط أفقي أعلى المتجر بدل القائمة الجانبية.
- الضغط على أي قسم يعرض منتجات هذا القسم فقط، وزر «الكل» يعرض كل المنتجات.
- ارفع الملفات الجديدة مع استبدال `index.html` و`style.css` و`app.js` في مستودع GitHub، واترك `data` و`assets` كما هي إذا لم تتغير.

## إصدار التصميم ثلاثي الأبعاد
- بطاقات المنتجات أصبحت بتأثيرات عمق وظلال ورفع عند المرور عليها.
- اسم المنتج يظهر بوضوح تحت صورته، مع شارة القسم والسعر وزر شراء أحمر.
- الأقسام مرتبة في شريط علوي، والفلترة تعرض منتجات القسم المختار فقط.
- تم الحفاظ على 72 صورة وبيانات المنتجات كما كانت في الإصدار السابق.
